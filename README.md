# HoopTwin: Basketball Player Comparison Engine

<img width="2448" height="1251" alt="HoopTwin Screenshot" src="https://github.com/user-attachments/assets/68bbc643-562c-408d-8253-1f6ba0b8ac06" />


Technologies: TypeScript, HTML, CSS, React, RESTful APIs, Next.js

Welcome to HoopTwin your own basketball player comparison website!

This is a basketball player comparison website that allows for accurate player to player comparison for both the regular and post-season. The API used was the nbaapi which provided concurrent data for regular and post-season statistics.

The website allows comparison of every NBA player from the years 2000 to current day. Both basic and advanced metrics are used to provide an accurate comparison for every player searched.

The search is split into two different sections that are reliant on two different algorithms. The algorithms used were KDTree and Brute Force with a K neighbor modifier to either shorten or lengthen the list of players wanted to be compared to.

To run this project in your IDE ensure Next.js is installed and run the command:

npm next dev

Then, open your browser to localhost:3000 to utilize the website.

Thank you, and enjoy!
